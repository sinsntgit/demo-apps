# SyncSense website (www.syncsense.in)

A static site generated by one Python script. It has no framework and no JavaScript build step, so every page is plain HTML that search engines and AI crawlers can read without running scripts.

Launch status, QA results, claims to confirm and the off-site SEO checklist are in [`docs/LAUNCH_NOTES.md`](docs/LAUNCH_NOTES.md).

## Layout

| Path | What it is |
|---|---|
| `build.py` | Site facts (email, phone, booking link, navigation, redirects), the shared layout, JSON-LD, sitemap, `llms.txt` and docs generation |
| `content/pages/**.html` | One file per page: a JSON header between `---` lines (path, title, description, keyword, FAQ, schema), then HTML |
| `content/data.py` | The 7 industry use case pages and 9 case studies, as structured data |
| `content/insights/*.html` | Articles (same format as pages, plus `date`) |
| `src/styles.css`, `src/site.js` | Styles; menus and the AskData sample demo |
| `src/contact.php` | Lead form handler: emails sales@syncsense.in, redirects to `/thank-you/` |
| `src/.htaccess` | Redirects (old URLs are filled in from `REDIRECTS` in `build.py`), trailing slashes, caching |
| `assets/` | Logo, share image, dashboard screenshots, approach PDF |
| `docs/` | Generated page table, placeholders list and redirect map, plus launch notes |
| `public/` | Build output (not committed) |

## Common edits

- **Booking link**: set `BOOKING_URL` in `build.py`. Every "Book a demo" button switches to it.
- **Change page text**: edit the page's file in `content/pages/`, or `content/data.py` for industries and case studies.
- **Fill a placeholder**: search for `[PLACEHOLDER:`, `[PROOF:` or `[CONFIRM:` and replace the whole marker with the real text.
- **Add an article**: copy a file in `content/insights/`, change its header (`path`, `title`, `description`, `h1`, `short`, `date`, `read`) and body.

The build fails if a page has no H1 or more than one, if a token is unknown or if two pages share a path. It warns when a title is over 60 characters or a description falls outside 140–155.

## Build and preview locally

```bash
python3 build.py
```

```bash
php -S 127.0.0.1:8000 -t public
```

The PHP server serves pages at their folder URLs, such as `/products/`. The redirects in `.htaccess` only work on Hostinger (Apache).

## Deploy to Hostinger

1. Run `python3 build.py`.
2. Zip the contents of `public/`, including `.htaccess`, into `site.zip`.
3. Upload `site.zip` to the website root with Hostinger's file upload.
4. Run the static archive deploy (`hosting_websites_deploy-static-site-archive` with `archive_path: site.zip`).

A deploy replaces everything on the website. The preview site is `resolute-mediumturquoise-seahorse-79.hostingersite.com`. Do not deploy to syncsense.in until the switch-over is agreed.
