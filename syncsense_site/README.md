# SyncSense website (syncsense.in)

Static rebuild of www.syncsense.in, which was previously a Hostinger Website Builder site.
It has the same pages, text, images and URLs, plus a working contact form.

## Layout

- `build.py`: page content and the shared header, footer and `<head>`. Edit page text here.
- `src/styles.css`: all styles.
- `src/contact.php`: contact form handler. Emails submissions to sales@syncsense.in.
- `src/.htaccess`: clean URLs (`/about` serves `about.html`), the syncsense.in → www redirect, caching headers.
- `assets/`: images (WebP, resized from the originals) and the downloadable approach PDF.
- `public/`: build output. Generated by `build.py`, not committed.

## Build

```bash
python3 build.py
```

## Preview locally

```bash
php -S 127.0.0.1:8000 -t public
```

This serves pages at `/about.html`. The clean `/about` URLs work only on Hostinger, through `.htaccess`.

## Deploy (Hostinger)

1. `python3 build.py`
2. Zip the contents of `public/` (including `.htaccess`) into `site.zip`.
3. Upload `site.zip` to the website root with the Hostinger file upload, then run the
   static archive deploy (`hosting_websites_deploy-static-site-archive`, `archive_path: site.zip`).
   A deploy replaces everything on the website.
